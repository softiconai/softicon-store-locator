A store locator block with a free OpenStreetMap map. Visitors find the nearest store by town, postcode or their location. No Google Maps API key.

== Description ==

**SoftIcon Store Locator** adds a **Store Locator** block to the block editor. Add your stores, branches or dealers in the block, and the page shows them as a list with a map.

* **No Google Maps API key, no billing** – the map uses OpenStreetMap.
* **Works without JavaScript** – the store list is real HTML with addresses and phone numbers, so search engines can read it.

== Installation ==

1. Install the plugin from Plugins → Add New, or upload the zip.
2. Activate it.
3. In the block editor, add the **Store Locator** block.
