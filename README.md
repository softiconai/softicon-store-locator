# SoftIcon Store Locator

A WordPress block that shows your stores, branches or dealers as a list with an OpenStreetMap map. Visitors find the nearest one by town, postcode or their own location. No Google Maps API key.

## Development

```bash
npm install
npm run start   # watch
npm run build   # production build
npm run lint
npm run zip     # build + translations + release zip
```

Shared editor helpers come from the `softicon-tools` folder next to this plugin. `npm run tools` copies them into `src/vendor/softicon-tools/` before each build.
